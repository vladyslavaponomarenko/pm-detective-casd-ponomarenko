| 4. Калькулятор ресурсів | Інструмент для маржинальності на команді з ростера (у Git) і планова маржинальність Christmas Reskin (файлом у застосунку). Усе, що захочеш додати до функціоналу, — плюс |

| ★ Відео, за бажанням | До 5 хвилин, у застосунку |
